# 🍚 경희대 거지맵 — 구글 시트 실시간 자동 연동 가이드 (1분 완성)

시트에서 메뉴 가격을 수정하거나 새 식당 행을 추가하면 **코드 수정 없이** 거지맵 웹앱에 바로 반영되는 세팅 방법입니다.

---

## Step 1. 구글 스프레드시트 원클릭 생성 (30초)
1. 브라우저 주소창에 **https://sheets.new** 를 입력해 새 구글 스프레드시트를 엽니다.
2. 상단 메뉴 **[확장 프로그램] → [Apps Script]** 를 클릭합니다.
3. 기존 코드를 지우고 같은 폴더의 **`setup_google_sheet.gs`** 파일 내용을 통째로 복사해 붙여넣은 뒤 저장(`Cmd + S` / `Ctrl + S`)합니다.
4. 상단 실행 함수 목록에서 **`setupGeojimapSheet`** 가 선택된 상태로 **[▶ 실행]** 버튼을 누릅니다. (최초 1회 권한 허용: `고급 → 이동 → 허용`)
5. 스프레드시트 탭으로 돌아오면 **65곳 전체 식당 목록 + 드롭다운 + 색상 하이라이트 + `📘 입력가이드` 탭 + 상단 `[🍚 거지맵 관리]` 전용 메뉴**가 자동으로 완성되어 있습니다!

---

## Step 2. 시트 공유 권한 켜기 (10초, 최초 1회)
1. 스프레드시트 우측 상단 초록색 **[공유]** 버튼을 클릭합니다.
2. 일반 액세스를 **`제한됨` → `링크가 있는 모든 사용자 (뷰어)`** 로 바꾸고 **[완료]** 를 누릅니다.
   - *(뷰어 권한이라 다른 사람은 절대 시트를 수정할 수 없고, 본인만 수정할 수 있으니 안전합니다!)*

---

## Step 3. 웹앱과 연결하기 (20초)
시트 상단 메뉴 **[🍚 거지맵 관리] → [🔗 웹앱(app.js) 자동연동 코드 확인·복사]** 를 클릭하면 내 시트 전용 연동 주소가 바로 뜹니다.

- **방법 A (내 브라우저에서 바로 연결·테스트)**:
  거지맵 웹앱 우측 상단 **`☰` 메뉴 → `📗 구글 시트 실시간 연동`** 입력칸에 시트 주소를 붙여넣고 **[연결]** 클릭!
- **방법 B (GitHub Pages 배포 시 모든 학우에게 영구 적용)**:
  복사한 `const GOOGLE_SHEET_CSV_URL = "https://docs.google.com/...";` 한 줄을 **`app.js` 맨 첫 번째 줄**에 덮어쓰고 저장!

---

## 💡 평소 관리 꿀팁
- **새 식당 추가**: 시트 상단 `[🍚 거지맵 관리] → [➕ 맨 아래 새 식당 행 추가]` 클릭 후 식당명·가격·메뉴 입력!
- **위도·경도(GPS) 자동 입력**: `address`(주소) 칸만 적어두고 `[🍚 거지맵 관리] → [📍 빈 위도·경도 주소로 자동 채우기]`를 누르면 좌표를 일일이 찾지 않아도 자동으로 채워집니다.
- **폐업 매장 숨기기**: `status`(V열) 드롭다운을 `운영` → **`폐업`** 으로 바꾸기만 하면 웹앱 지도·목록에서 즉시 자동 제외됩니다.
